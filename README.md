# EmpowerTech: AI Workflow Automation with n8n

Course repository for the AMDR Foundation's flagship n8n course: an 8-week, 30-hour instructor-led cohort that takes non-technical adult learners and enterprise staff from a first scheduled workflow to AI chains, an agent with a human approval step, and a documented, production-ready capstone.

**Organisation:** AMDR Foundation Inc, a 501(c)(3) public charity in Atlanta, Georgia, delivering in Atlanta and Kingston, Jamaica. https://amdrfoundation.org
**Lead instructor:** Alicia Graham, n8n Ambassador (Atlanta and Jamaica), verified n8n Creator.
**Contact:** alicia@amdrfoundation.org

## What lives here

| Folder | Contents |
|---|---|
| `modules/00-orientation` to `modules/08-capstone` | One folder per module: starter workflow JSON, lab sheet, facilitator notes |
| `rubric/` | Capstone and lab assessment rubric |
| `facilitator-guide/` | Run-of-show, timing, and troubleshooting for each live session |
| `exemplars/` | De-branded production workflows used as teaching examples |

Content is added module by module as the course is built. Starter workflows import into n8n Cloud or a self-hosted n8n instance with **Import from file**.

## Course outline

| Module | Title | Hours |
|---|---|---|
| 0 | Orientation: accounts, workspace, first run | 2 |
| 1 | Triggers and data flow | 3 |
| 2 | Expressions and data transformation | 3 |
| 3 | Logic, branching and sub-workflows | 3 |
| 4 | APIs, webhooks and authentication | 4 |
| 5 | AI chains, classifiers and extractors | 4 |
| 6 | Agents, tools and memory | 4 |
| 7 | Error handling, testing and production readiness (enterprise edition: governance lab) | 3 |
| 8 | Capstone build, review and showcase | 4 |

Two editions share this spine: a **Community** cohort (open enrolment, up to 20 learners) and an **Enterprise** cohort (private, 8 to 15 learners, delivered in the employer's n8n workspace).

## Delivery platforms

- Live sessions: Google Meet
- Learning platform: Google Classroom (class code shared on enrolment)
- Hands-on: n8n Cloud trial or a Foundation-hosted n8n instance for scholarship learners
- This repository: starter files, lab sheets and the rubric
